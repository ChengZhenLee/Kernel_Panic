# Weapon FX sheets (all weapons)

Hand-paletted pixel sprite sheets for the evolution weapons and the base weapons, played in-engine by `scripts/fx/weapon_fx.gd` (looping parts) and `scripts/fx/sprite_fx.gd` (one-shots: `SpriteFx.play(sheet, world_pos, scale)`). Transparent background, hard-edged pixels only (fades use ordered dither), 5-colour ramp per effect, outlined. Generated by `tools/gen_weapon_fx.py <outdir>` (re-run to tweak; `manifest.json` carries the same numbers as the tables below). Every sheet is a **horizontal strip** of equal frames at **12 fps**, imported with texture filter **Nearest**.

Parts whose size follows the weapon's radius (dither fills, rim lines, shock rings, the Scanner sweep, Ping/Tesla chains) are still drawn in code with `scripts/fx/pix.gd` (whole-pixel squares) around the sprites. If a sheet is missing, the weapon falls back to its code-drawn version.
