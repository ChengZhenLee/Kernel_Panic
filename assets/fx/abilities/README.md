# Ability FX (pixel art)

Hand-paletted pixel sprite sheets for the eleven class abilities, replacing the code-drawn marks in `scripts/fx/ability_fx.gd`. Transparent background, hard-edged pixels only (no antialiasing; fades use ordered dither), 5-colour ramp per ability. Generated by `tools/gen_ability_fx.py` (re-run to tweak). `manifest.json` carries the same numbers as the tables below.

Every sheet is a **horizontal strip** of equal frames, **12 fps** (matches the weapon FX). Import with texture filter **Nearest**. Square impact sheets are authored at reference radius **88 px** inside a 192x192 frame, centre (96,96); to match the game radius, scale the sprite by `game_radius / 88` (e.g. RESTORE `130*m` -> ~1.5x, WILDFIRE `480*m` -> ~5.5x). Fade out by frame, not alpha.

**Three tiers:** standard (88 px reference radius, 192px frames), then the evolution-class abilities Rail Strike, Wildfire, Deep Freeze and Thunderstorm are FLAGSHIP: 384px frames (640x160 for Rail Strike), 20-24 frames, 170 px reference radius (scale by `game_radius / 170`), layered multi-stage animation with shading and outlines. They are deliberately richer than the evolution weapon FX.

Aura timing: start looping on cast, fade in over ~0.15 s (modulate alpha), on end finish the current loop and fade out over 0.25 s (same as `stop()` in ability_fx.gd). Auras sit centred on the player; scale 1x.

Palettes: PAUSE is bronze/gold clockwork (not the class colour). Other game colours are baked in per ability (class colour from `classes.gd`: LOCKDOWN blue, DEEP SCAN teal, RESTORE green, PHASE violet, PURGE gold). If an ability's class colour changes, re-run the generator with the new palette. Directional sheets (phase, railstrike) are authored left to right: rotate to the aim direction and stretch X for the dash/beam length (see notes). `sup`/super variants are not separate art: scale up ~1.3x or play the sheet twice offset by 3 frames.
